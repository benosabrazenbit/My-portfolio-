# Brazen Benosa — Futuristic Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — futuristic responsive design
- `script.js` — mobile menu, scroll reveal, and footer year

## Before publishing
1. Open `index.html`.
2. Replace the sample project descriptions with your real projects.
3. Replace `your.email@example.com` in the Contact button with your email address.
4. Update the About and Skills sections so they accurately represent you.
5. Add project links or screenshots if you have them.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required. Google Fonts are loaded from the internet; system fallback fonts are included.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `my-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. The public URL will appear in the Pages settings.

Because this is a static site and uses relative file paths, it works on a GitHub Pages project URL without extra configuration.
